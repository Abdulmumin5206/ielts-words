# Twin Words

A small offline vocabulary app for IELTS Reading, made for practising on the bus.

- 177 important words from the next Cambridge Reading tests (one pack per test) plus words used in IELTS questions.
- Each word: easy English meaning, Turkish, its "twins" (the paraphrases a text may use), an example and audio.
- Spaced practice: learn card, then meaning / twin / gap / typing checks. Wrong answers come back.
- Progress stays on the phone (localStorage). "Share my progress" exports it.

Open on iPhone in Safari, tap Share, then Add to Home Screen. After the first open it works offline.

Tests: open `index.html?test` (separate storage) and read the result at the bottom of the page.
